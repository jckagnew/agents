# 🔑 API Keys Quick Reference Card

## 🚀 **Get All API Keys in 10 Minutes**

### **1. Unsplash API (FREE) - 2 minutes**
- **Link**: https://unsplash.com/developers
- **Steps**: Sign up → Your apps → New Application → Fill form → Get Access Key
- **Cost**: FREE
- **Rate Limit**: 50 requests/hour

### **2. Pexels API (FREE) - 2 minutes**
- **Link**: https://www.pexels.com/api/
- **Steps**: Sign up → Request API Key → Fill form → Get instant approval
- **Cost**: FREE
- **Rate Limit**: 200 requests/hour

### **3. Stability AI API (CHEAP) - 3 minutes**
- **Link**: https://platform.stability.ai/
- **Steps**: Sign up → API Keys → Create API Key → Add $10 deposit
- **Cost**: $0.002 per image
- **Rate Limit**: 150 requests/minute

### **4. OpenAI API (You Already Have)**
- **Link**: https://platform.openai.com/api-keys
- **Steps**: Login → Copy existing key or create new one
- **Cost**: $0.040 per image
- **Rate Limit**: 50 requests/minute
