# Legal Toolkit (Drafts for Counsel Review)

> **Important**  
> These documents were prepared by Codex as working drafts. They are **not** legal advice and have **not** been reviewed by licensed counsel. Before using anything in production, have a qualified attorney admitted in Texas review and adapt the language to your specific circumstances.

## Contents

- `templates/` – Markdown drafts for core agreements and policies you can customize before sending to counsel.
- `checklists/` – Step-by-step task lists that highlight where human input (you or your attorney) is required.

## Recommended Usage

1. Fill in the brackets (`[LIKE_THIS]`) with your facts.
2. Flag open questions or optional clauses in `TODO:` notes.
3. Export or copy the file to your preferred editor.
4. Share the marked-up version with counsel for feedback.

## Quick Start

```bash
# view all templates
ls legal/templates

# open a specific draft
code legal/templates/operating-agreement.md
```
