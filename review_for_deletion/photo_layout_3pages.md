## Maximum Photo Sizes with 3 Pages

### Option 1: 2 Photos per Page (Recommended)
- **Photo Size**: 7" x 5" each
- **Total Pages**: 3 (6 photos on first 3 pages, 2 photos on last page)
- **Margins**: 0.5" on all sides
- **Spacing**: 0.5" between photos

### Option 2: 3 Photos per Page (Mixed Sizes)
- **Large Photo**: 6" x 4" (landscape)
- **Small Photos**: 3" x 4" each (portrait)
- **Total Pages**: 3
- **Page 1**: 1 large + 2 small
- **Page 2**: 1 large + 2 small
- **Page 3**: 1 large + 1 small

### Option 3: 4 Photos per Page (2x2 grid)
- **Photo Size**: 3.5" x 5" each
- **Total Pages**: 2 (8 photos total)
- **Margins**: 0.5" on all sides
- **Spacing**: 0.25" between photos

## Final Recommendation

**Use 2 photos per page at 7" x 5" each**
- **Page 1**: Photos 1, 2
- **Page 2**: Photos 3, 4  
- **Page 3**: Photos 5, 6
- **Page 4**: Photos 7, 8 (if you want to keep it to 3 pages, use 3 photos on page 3)

## Canva Setup Instructions

### For 7" x 5" Photos (2 per page):
1. Create 3 separate 8.5" x 11" designs
2. Upload all 8 photos
3. Resize each photo to 7" x 5" (maintain aspect ratio)
4. Position 2 photos per page, centered
5. Set margins to 0.5" on all sides
6. Add 0.5" spacing between photos

### For 3.5" x 5" Photos (4 per page):
1. Create 2 separate 8.5" x 11" designs
2. Upload all 8 photos
3. Resize each photo to 3.5" x 5" (maintain aspect ratio)
4. Position in 2x2 grid
5. Set margins to 0.5" on all sides
6. Add 0.25" spacing between photos

## Print Settings
- **Paper Size**: 8.5" x 11"
- **Orientation**: Portrait
- **Quality**: High (300 DPI recommended)
- **Margins**: 0.5" minimum
- **Bleed**: Not needed for this layout
