🐳 ntfy.sh Docker Test Interface

🐳 Docker Commands You're Learning:

Here are the Docker commands you can practice with this setup:

Basic Container Management:

# View running containers
docker ps

# View all containers (including stopped)
docker ps -a

# View container logs
docker logs ntfy

# Stop the service
docker compose down

# Start the service
docker compose up -d

# Restart the service
docker compose restart

Container Inspection:

# Get detailed container info
docker inspect ntfy

# Enter the container
docker exec -it ntfy sh

# View container resource usage
docker stats ntfy

Testing Notifications:

# Send a simple notification
curl -d "Hello Docker!" http://localhost:8080/mytopic

# Send with priority
curl -d "High priority message" -H "X-Priority: 5" http://localhost:8080/mytopic

# Send with title
curl -d "Test message" -H "X-Title: Test Notification" http://localhost:8080/mytopic
