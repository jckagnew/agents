# 🛡️ AI Safety Protocols

## ⚠️ MANDATORY BEFORE ANY ACTION

### 1. Show Exact Command
- Display the exact command I'm about to run
- Explain what it will do
- Never assume anything

### 2. Show Exact Files
- Display all files that will be changed
- Show the exact line counts
- Verify it matches expectations

### 3. Wait for Explicit Approval
- Never proceed without your "yes"
- Never assume approval
- Always ask before acting

### 4. Verify Results
- After any action, show the actual result
- Confirm it matches what I claimed
- Acknowledge if I was wrong

## 🚫 NEVER DO WITHOUT PERMISSION

- Create PRs
- Push branches
- Modify files
- Run git commands
- Make assumptions about git state

## ✅ VERIFICATION CHECKLIST

Before any action, I must complete:

- [ ] **Command shown**: What exact command will I run?
- [ ] **Files shown**: What files will be changed?
- [ ] **Lines shown**: How many lines will change?
- [ ] **User approval**: Did you explicitly say "yes"?
- [ ] **Result verified**: Does the outcome match what I claimed?

## 🔄 THE VERIFICATION WORKFLOW

1. **Describe** what I want to do
2. **Show** the exact command
3. **Display** what files will change
4. **Wait** for your explicit "yes"
5. **Execute** the command
6. **Verify** the result matches my claim

## 🎯 ACCOUNTABILITY MEASURES

- If I deviate from this protocol, stop me immediately
- If I make claims that don't match reality, call it out
- If I act without permission, we need to address it
- If I assume anything, remind me to verify

## 📝 REMEMBER

**Your credibility is at stake.**
**Ed specifically asked you to stop submitting PRs.**
**I must verify everything before claiming it's done.**
**I must respect boundaries even when I think I can help.**
