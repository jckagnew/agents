## 1. BMAD Framework Overview

### Core Concepts
BMAD (Breakthrough Method for Agile AI Driven Development) is a structured methodology for AI-driven development that creates specialized AI agents with specific roles and workflows:

- **Specialized Agents**: Role-based AI agents (Analyst, PM, Architect, Scrum Master)
- **Structured Workflows**: Documented processes and templates for consistent execution
- **Institutional Knowledge**: Capturable and repeatable methodologies
- **Domain-Specific Expansion Packs**: Customizable frameworks for specific domains

### Key Features
1. **Role-Based Agent Architecture**
   ```yaml
   agent:
     name: Domain Expert
     role: Primary function
     style: Communication approach
     identity: Background that shapes perspective
     focus: What problems this agent solves
   ```

2. **Structured Workflows**
   ```yaml
   task:
     id: analyze-problem
     description: Systematic problem analysis
     workflow:
       - step: Gather context
       - step: Identify constraints
       - step: Define success criteria
   ```

3. **Template-Based Outputs**
   ```yaml
   templates:
     - output-structure-tmpl.yaml
     - data-story-tmpl.yaml
     - linkedin-post-tmpl.yaml
   ```

4. **Quality Gates and Checklists**
   - Validation steps for consistent output quality
   - Handoff procedures between agents
   - Documentation requirements
